Age Calculator Web App

A modern and responsive Age Calculator web application that accurately calculates a user’s age based on their date of birth using pure JavaScript.

🚀 Project Overview

Age Calculator is a lightweight front-end project designed to demonstrate clean JavaScript logic, date manipulation, and user-friendly UI practices.
The application instantly calculates the user's age after selecting a birth date, without any external libraries or frameworks.

✨ Features

📅 Accurate age calculation based on birth date

⚡ Instant results without page reload

🎯 Clean & minimal UI

🌐 Fully responsive (Desktop & Mobile)

🧠 Pure JavaScript (No libraries)

🛠️ Built With

HTML5 – Semantic structure

CSS3 – Styling & layout

JavaScript (ES6) – Logic & date calculations

⚙️ How It Works

User selects their Date of Birth

JavaScript calculates the difference between the current date and the selected date

The age is displayed instantly in years (and optionally months & days)
